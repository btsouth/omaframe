# Omaframe 0.7.2

Framed scrollshots no longer gain a wide grey strip beside Chromium’s
scrollbar. The frame renderer now treats headers and footers as part of
the edge, even on very tall captures.

The full capture width and window controls are preserved. Raw output is
unchanged, and the original scrollbar remains its original width.

Install or update with the attached `omaframe-x86_64.pkg.tar.zst` package,
then reopen Omaframe. Existing settings, captures and drafts are preserved.

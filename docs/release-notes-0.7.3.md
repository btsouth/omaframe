# Omaframe 0.7.3

Scrollshots no longer repeat native scrollbar thumbs and arrow buttons
beside the captured page. The full window width, header and footer controls
stay intact.

Cleanup uses verified scroll motion and a mostly flat page margin. Unconfirmed
controls and textured edges are preserved.

Install or update with the attached `omaframe-x86_64.pkg.tar.zst` package,
then reopen Omaframe. Existing settings, captures and drafts are preserved.
